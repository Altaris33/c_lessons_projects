# C Projects

A collection of small projects, lessons,  and experiments written in C.

## Projects

### Pointers

A collection of C programs that shows how to use pointers in C.

### Structures

A collection of C programs that shows how to use structs and unions.

### Macros

A collection of C programs that shows how to use macros in C.

## Building

Each project is independent. See the README and Makefile inside
the corresponding project directory.
